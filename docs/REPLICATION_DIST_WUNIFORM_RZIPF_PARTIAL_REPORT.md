## Note on interpretation

With write=Uniform and read=Zipf, writer updates spread across the whole keyspace while readers concentrate on the Zipf hot set (index 0 hottest). Compare against write=Zipf/read=Zipf (`REPLICATION_DIST_WZIPF_RZIPF_REPORT.md`), where writers and readers share the same hot set: that report showed Zipf reads degrading with m from hot-key read/replay contention. Here the writers are spread out, so hot-key contention on the replica should be lower; the m=1/4/8 data below is the available slice for that comparison. The disjoint-hot-set case (write=ZipfRev) was not run.

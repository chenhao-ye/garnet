# Replication Sweep: write=Zipf, read=Zipf -- Performance Report

Full 180-combo replication sweep on `code-replication` with **writer keys Zipf-distributed** and **reader keys Zipf-distributed** (theta 0.99), run under pinned maximum CPU frequency. Config `replication_dist_wzipf_rzipf`.

## 1. Setup

primary=node0, replica=node1, client=node2 (144 HW threads each). Diskless sync, null-device AOF. run.py pins the performance governor on all three nodes.

| Knob | Value |
|---|---|
| writer key distribution | **Zipf** |
| reader key distribution | **Zipf** (theta 0.99) |
| dbsize | 10,000,000 keys | 
| readers | 16 (itp=256) | 
| runtime x repeats | 30 s x 3 (median) |
| AOF memory | 1 GB per sublog |
| ship / replica budget | 256 MB / 256 MB (summed) |

Swept: writers {1,2,4,8,16,32} x sublogs m {1,4,8,16,32} x drift {10k,30k,100k,300k,1M,2.4M} (4us..1ms). 6x5x6 = 180 combos.
